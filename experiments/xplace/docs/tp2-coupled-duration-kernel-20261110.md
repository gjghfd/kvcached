# 共享时间线上的条件时长推演

`runtime/coupled_duration.py`实现数值离散事件推演，不再只校验输入。它尚不是可部署的预测器：没有训练好的残余初态模型或实测响应系数，不接入placement评分，不改变容量检查，不能通过GPU或15%/30%精度门。所有本轮数值仅用于合成算术测试。

## 时间与服务模型

两个tenant各持有一个同步rank批次。每rank按照显式请求顺序、token/request上限和chunk上限构建批次；一个tenant批次完成是各rank的共同模型边界。请求依次经历prompt、已知输出重算和逐token decode。重算输入不伪造新输出，最后prompt输入可直接产生首输出。每次模型计算后仍有独立return阶段，随后按照显式控制端采样周期、相位和传输延迟产生收讫事件。

响应表以`model:own_phase:peer_phase`索引，提供完整归一化服务量的秒数；特征包括双方最大rank token数、上下文和、batch数及迁移字节数。每行显式给出截距、系数和适用区间，没有默认实测参数、邻桶外推或旧失败常数回退。两个方向独立索引，不能拿own桶替peer桶。

每个活动阶段开始时剩余服务份额为1。设当前响应为D、推进时间为dt，则剩余份额减少dt/D。下一事件取两个阶段完成、收讫、准入的最早时刻。同一时刻双方完成一起结算，再重算下一段的相互影响；peer从prefill转return/decode时，正在执行的批次只重估剩余份额，不从头重新收费。循环在全cohort收到共同里程碑时结束，而不是固定wall-time的N乘H。

采样相位只在距整数不超过32 ULP时做数值边界对齐，避免浮点误差被向上取整放大为整个采样周期；返回时间仍不早于模型完成时刻。明显越过边界的完成仍等下一周期。这是本地数值稳定措施，不修改生产观测时间戳。

这是**分段服务率假设**，不是GPU kernel模拟，也不是将实测完整step延迟直接变成可识别的瞬时速率。条件速率能否从新数据识别、host等待与计算是否可这样分解，都需要实测检验；不能仅把r2/r4旧均值填表就宣称模型有效。

## 残余、迁移与完整cohort

入口要求已有账本绑定reference。基线与候选使用同一reference、显式as-of初态、响应表和观测协议，并分别记录hash。初态必须由未来残余模型提供，含估计的已返回输入前缀、scheduler输出、未收讫输出事件、单个在途批次及剩余服务份额。采样年龄造成的已推进工作在初态内体现，**不把原样本直接冒充as-of进度**。源码不从wave布尔量或host栈推导完成比例，也不提供零延迟默认初态。

初态可以表达部分在途计算、等待host返回、零输入但待采样返回、无请求但仍有残余活动。未覆盖的在途区间、缺待收讫输出、多在途批次、缺残余来源和过期绑定均拒绝。初态中的进度是条件估计，不是GPU真值，更不是未来真实输出长度；目标仍为原样本O+K，不随估计或候选改变。

迁移先等已有批次返回，再进行显式drain和transfer阶段，传输完成才改rank。它不是已完成迁移的瞬移，也不是暂停peer的分时策略。基线不准入的外部arrival仍留在cohort；必须另有未来基线重试/准入时刻的预测，否则保留未服务/超时结果，不能删掉请求或算零成本。

快请求越过自身K后继续计算和干扰至共同终点。每个请求保留结果行；未全到目标、覆盖不足、无进展或超过时间/事件界限时，总目标为null，已完成子集只保留诊断。EOS和失败由既有独立outcome审计保留；这个闭cohort、无EOS的条件推演不预测生存率，不替代全量trace结果。

## 当前边界

此模型采用单批次rank-barrier、明确请求顺序的近似；不是vLLM调度器复刻。实际归档engine同时存在`step`与`step_with_batch_queue`，取决于`max_concurrent_batches`。先前六角色账本配置并未证明batch queue深度、真实rank同步、队列顺序及worker行为；不能凭`async_scheduling=False`就接受此推演模型的部署条件。没有完整能力证明时仍不能接评分。

resident waiting请求的调度/容量准入尚未建模，入口明确拒绝，不将它自动变running。外部arrival的准入时刻属于显式动作预测，不由这个内核自行寻找空位。候选布局的完整容量与迁移可行性仍由独立安全检查负责。

最大rank特征也不是完整rank布局或GPU资源争用描述。CPU对称性/阶段转换测试只能证明实现符合该近似。后续必须实现可部署残余估计，验证实际pipeline深度/批次分配，冻结训练与独立holdout、K、采样周期/截止和开销协议，再决定是否保留或修订模型。缺支持点按失败/缺失报告，不筛种子、不改Conv输出、不用预测干扰缩减容量reserve。

r1–r4已查看，仍全为探索数据。未校准的条件数值不是独立预测结果；实测预测和长上下文/容量门通过前不做正式消融，TP2配对通过前不做混合拓扑。
