# r4 Host残余探索：不足以接入完整评分

新增返回残余估计已在真实r4 host记录上拟合并完成顺序回放，但**没有获得可部署的联合时长预测器**。这是对已看过数据的探索，不是独立holdout，指标也不是原先15%/30%的联合预测验收指标。

## 范围与结果

- 24个原case全部保留；12个timing-off没有host观测，明确记为缺失，不能当作零干扰。
- 12个timing-on共223,752个外层host调用，全部正常返回；本数据中异常和右截尾均为0，相关实现另有合成测试。
- 100ms固定网格生成50,750个虚拟查询；34,421个有支持，覆盖率67.8246%。其余4,283个缺训练组、12,046个风险集/跨case支持不足，均保留逐行结果。
- 有支持且有标签点的受限剩余时间MAE为0.210211秒，WAPE为63.9640%；这是条件子集误差，不能掩盖32.1754%的不可用查询。H固定为2秒，零收讫延迟只用于离线回放，未测live socket开销。

## 含义与下一步

按host类型、tenant和lane拟合的边际持续时间分布能产生数值预测，但这里的残余误差与覆盖缺口不足以支持将其接入评分。跨负载变化、同进程相关性和缺少当前batch/peer状态是需要检验的模型缺项，不能从这次误差直接断言根因。不得通过筛case、改H或风险集门槛把本次结果改成成功。

Host返回目标仍与输出里程碑不同，也不能识别GPU已经完成多少工作。要推进完整模型，应为新的训练/独立验收pilot预先确定可实时取得的batch分配、host调用身份及scheduler输出返回关联，再校准共同初态与阶段响应；保持本次模型、全部预测行和负结果原样保存。没有新GPU提交或正式消融，容量reserve与所有实验门槛不变。
